# Mermaid Flow Studio

תיקיית האפליקציה הייעודית של ה-studio.

## מה יש כאן
- `src/shared` מנוע ה-Mermaid והמודלים המשותפים
- `src/web` ה-React studio ל-standalone ול-widget
- `src/server` שרת ה-API המקומי ושרת ה-MCP
- `open_studio.*` פתיחה מהירה בדפדפן

## הפעלה
- `npm run build`
- `npm run dev`
- לפתוח `http://127.0.0.1:3210/`

השרת קורא את קבצי ה-`.mmd` מתיקיית האב:
- `C:\Users\alroy\projects\personal-flows`
