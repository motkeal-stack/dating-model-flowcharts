# Personal Flows

ברוך הבא לריפו של התזרים (Flows) האישיים שלי!
כאן מרוכזים כל מסמכי התזרים, התרשימים וקטעי הקוד הקשורים לתהליכים שונים שאני בונה.

## מבנה הריפו
בהמשך נוסיף לכאן תיקיות לכל נושא או תזרים ספציפי (למשל תזרימים הקשורים לדייטינג, עבודה, פרויקטים אישיים ועוד).

## איך להשתמש
כל תזרים יקבל תיקייה משלו עם קוד, תרשימים והסברים נוספים רלוונטיים.
